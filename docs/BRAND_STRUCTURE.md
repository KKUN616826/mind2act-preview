# Mind2Act 品牌结构

| 层级 | 名称 | 用途 |
|---|---|---|
| 总品牌 | Mind2Act | 导航、项目总称 |
| Benchmark | Mind2Act World | 任务、评测维度与排行榜 |
| 模型方案 | Mind2Act Harness | Astra–Jev 结构化交接、工作记忆与成本路由 |

World 副标题：Evaluating Reasoning–Acting Coordination in Robotic Manipulation。

Harness 副标题：Contract-Guided Coordination of Cognitive and Reactive Agents for Robotic Manipulation。

本轮更新当前网站、构建源、公开结构数据、当前文档与使用中的方法图。保留 GitHub 仓库名、`mindaccord/` 子目录和既有下载文件名以兼容历史链接。历史更新记录、归档图片和原版 PDF 不追溯更名。未改任务定义、候选模型或测评状态。
