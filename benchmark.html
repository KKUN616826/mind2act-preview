A benchmark for closed-loop robotic manipulation

15 tasks across Mind, Act, and Mind2Act. Each task has Easy, Medium, and Hard configurations.

Mind

Memory-driven task decisions: entity, feedback, process, spatial, and integrated memory.

E Duplicate Item Identification

Identify previously observed items across successive batches and place each repeated item in the submission tray.

Evaluation dimensions

Entity memory; cross-batch retrieval; target selection and physical submission.

F Unknown Button Mapping and Slider Navigation

Infer an unknown button-to-motion mapping from feedback, retain it after reset, and navigate to the target.

Evaluation dimensions

Feedback-based rule inference; mapping retention; route planning.

P Order-Based Meal Assembly

Remember initial and additional orders and deliver the requested ingredients to the correct containers.

Evaluation dimensions

Order memory; accumulated demand tracking; correct ingredient delivery.

S Rotating Tray Layout Reconstruction

Remember a colored-slot arrangement and restore it after the tray rotates.

Evaluation dimensions

Spatial memory; rotation tracking; matching placement.

M Workpiece Tracking and Route Reproduction

Track a hidden target through cover exchanges and reproduce its required station route.

Evaluation dimensions

Target tracking; route memory; ordered station completion.

Act

Dynamic response, precision, contact, and stable physical execution.

FR1 Continuous Conveyor Picking

Pick moving packages from a conveyor and place them in the collection tray.

Evaluation dimensions

Dynamic target interception; grasp timing; stable deposit.

FR2 Light-Guided Button Response

Respond to illuminated button cues with timely, correct presses and releases.

Evaluation dimensions

Cue response time; button selection; press and release control.

PR1 Linear Resistor Adjustment

Adjust a linear resistor to the target reading and maintain it after release.

Evaluation dimensions

Position precision; resistance adjustment; stability after release.

PR2 Rotary Voltage Regulator Setting

Adjust a rotary voltage regulator to the target reading and maintain it after release.

Evaluation dimensions

Rotational precision; voltage adjustment; stability after release.

PR3 Marker Line Tracing

Grasp a marker and trace a visible path with controlled contact and precision.

Evaluation dimensions

Path accuracy; tool contact; tracing continuity.

Mind2Act

Reasoning and execution coordinated across multi-stage tasks.

CP01 Conveyor Meal Assembly

Remember reference orders and assemble meals from a continuously moving food supply.

Evaluation dimensions

Order memory; moving-target grasping; meal completion.

CP02 Rotating Cake Decoration

Remember a decoration layout and reproduce it on a rotating cake while completing the required stages.

Evaluation dimensions

Arrangement memory; rotating-target placement; stage prerequisites.

CP03 Dynamic Rack Loading

Load upright plates into moving empty rack slots without disturbing other plates.

Evaluation dimensions

Moving-slot timing; upright insertion; contact stability.

CP04 Dual-Arm Cooking

Remember a recipe and coordinate preparation, cooking, temperature control, and cleanup.

Evaluation dimensions

Recipe sequence memory; dual-arm coordination; temperature feedback and phase progression.

CP05 Keyboard Sequence Reproduction

Remember a demonstrated key sequence, reproduce it with mallets, and return the tools.

Evaluation dimensions

Key sequence memory; precise key contact and release; tool handling and preparation.
