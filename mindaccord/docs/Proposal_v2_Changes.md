# Proposal v2 的范围变化

## RSI 近期实现设计

RSI 纳入下一阶段的直接实现范围。方法扩展为局内协作与局间改进两个闭环：Critic 从开发记录提出经验或策略候选，独立验证后发布版本，失败保留或回滚；每局固定快照。首版复用原双 Agent 的 Record、批次、双经验库和发布基础，先接通经验闭环，再扩展受限交接／调度补丁。当前仍是设计，不声明 Jev RSI 已实现或有效。

实验说明保留概述：新增冻结版本与自主更新的对照方向，计入改进开销，正式测试不反馈到更新过程。

## 2026-09-24：基于执行反馈的推理分配

研究主线从模块组合进一步收束为：面向目标可复用、执行证据会变化的多步机器人任务，检验何时由 Jev 继续局部选择，何时需要更新视觉理解。沿用原有提案章节、网页入口与方法图，更新研究问题、职责、接口、记忆、调度及评测设计。

- 以通用视觉工具 Agent 的观察时效和推理开销为问题起点，明确适用任务及不预设收益的条件。
- Jev 的选择包括动作、信息获取与升级；普通动作绑定输入后一次选择，详情单独分级。
- 动作记忆由 Jev 主动管理、程序固定编码；Cognitive 持久会话独立。原自动摘要与 pinned facts 设计不作为当前实现。
- 区分已有巡检／固定事件触发和待验证的按需认知更新。
- 正文概述 Case7 可运行性、结论边界与验证方向；逐次运行和计数保存在数据记录中，不把单场景结果解读为比较优势。
- 将评测拆成选择器、认知更新与整体系统对照，避免把工具支持变化归因于 Jev。

本次更新不改变机器人运行代码，不启动实验；详细来源与结论边界见完整 proposal。Case7 的历史 RGB-D 授权不自动适用于 RoboDojo。
