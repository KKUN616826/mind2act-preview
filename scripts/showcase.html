03 / DIAGNOSTIC PROTOCOL

从“失败了”，追问到“哪里失效”。

评测设计面向两类系统。它们共享任务目标与环境侧完成条件，并分别记录观察权限、动作接口、训练条件和时间预算。

诊断问题可观察的失败示例需要的证据
目标是否选对？订单需要薯条，却选择了汉堡选择对象、目标位置及任务条件；不能只依赖口述推理
正确目标是否实现？选对食品，但抓空或落在盘外有效抓持、释放与稳定入盘等环境事件
效果是否用于下一步？尚未入盘，后续行为却跳过这一需求动作前后状态及后续选择；内部状态不可见时保留归因不确定性

用对照检验假设。

可合法替换接口的系统，可比较原生决策＋可靠执行、正确子目标＋原生执行与完整系统；使用相同任务条件，记录各设置的信息权限、操作时长与预算。端到端模型使用可实施的观察或反馈干预。轨迹分叉后，分数差不能直接解释为纯粹的模块贡献。

面向两类系统，分别披露接口。

TRACK A

Coding Agents

模型根据观察与历史生成工具调用，通过声明的感知工具与执行接口操作机器人。关注目标选择、工具使用、反馈解释与任务推进。

观察与历史→Agent 决策→固定执行接口→物理效果
TRACK B

E2E VLA / WAM

学习式策略从声明的观察与指令输入生成动作或动作块。关注完整任务行为，以及历史、物理约束和执行反馈在连续控制中的作用。

观察与指令→VLA / WAM→动作块→物理效果

由环境侧判据确认完成。两条路径的接口和训练条件分别披露；协同要求描述的是任务依赖，不要求模型显式拆成认知与动作模块。

任务成功

最终物理状态满足任务目标及约束。

有效进度

当前仍成立的阶段完成条件与前置依赖。

物理残差

位置、角度、剂量或接触轨迹的任务特定误差。

时限与效率

交互吞吐、端到端时延及窗口错失。

恢复成本

偏差后的额外操作、时间和资源消耗。

持续环境时钟

动态场景需记录环境是否在模型推理期间继续推进。持续时钟与暂停推理条件分别报告，有效交互频率与控制器内部步频分别计算。

可解释的诊断

可替换接口的系统可使用认知侧或执行侧的 oracle 对照；其他系统可采用可实施的观察、反馈干预。按实际证据区分目标、动作和进度错误。

尚待验证：完整系统是否出现基础能力测试无法解释的失败？反馈干预是否影响进度更新和恢复？需先固定运行配置、标定阈值并完成重复实验；当前没有模型排名或协同瓶颈的实证结论。

COMPANION METHOD / ASTRA–JEV PROPOSAL

Mind2Act Harness

Contract-Guided Coordination of Cognitive and Reactive Agents for Robotic Manipulation

新版方案聚焦成本感知的 Astra–Jev 协同：GPT-6 Astra 拆解子任务并调用感知工具，harness 将结果、候选与工作记忆编译为结构化文本，Jev 选择当前适用候选，由 Runtime 核验后执行。

Evidence-Grounded State

交接保留观测来源、坐标系、时效和未知项，区分动作回执与实际效果。

Candidate-Constrained Jev

Jev 选择绑定完整动作的候选 ID；连续参数、授权和失效检查由 harness 处理。

Budgeted Memory & Routing

保留任务关键事实，按事件局部刷新或升级 Astra，计入所有感知、摘要、重试与执行成本。

方法状态以最新 Harness 页面为准：已有外部 Case7 开发原型，RSI 与正式 benchmark 的收益仍待验证。此处 case 更新不产生新的模型成绩或成本结论。
