Keyboard Sequence Reproduction

Remember a demonstrated key sequence, reproduce it with mallets, and return the tools.

EasyMediumHard

Instruction

Pick up the left mallet, tap Play, watch and remember the demonstrated key sequence, reproduce it with the mallet, then return the tool. No rhythm matching is required.

Instruction

Pick up both mallets, tap Play, watch and remember the demonstrated key sequence, reproduce it with the mallets, then return both tools. No rhythm matching is required.

Instruction

Set the volume slider to MAX. Pick up both mallets, tap Play, watch and remember the demonstrated key sequence, reproduce it with the mallets, then return both tools. No rhythm matching is required.
