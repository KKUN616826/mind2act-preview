Mind2Act · CP03

Dynamic Rack Loading

Load upright plates into moving empty rack slots without disturbing other plates.

Evaluation dimensions

Moving-slot timing; upright insertion; contact stability.

Easy · Medium · Hard

Easy

Load 3 upright plates into the moving empty slots without disturbing other plates. Press Start before loading.

Medium

Load 5 upright plates into the moving empty slots without disturbing other plates. Set gear 2, release the lever, then press Start before loading.

Hard

Load 7 upright plates into the moving empty slots without disturbing other plates. Set gear 3, release the lever, then press Start before loading.
