# MindActWorld 网站叙事与命名更新

主标题为 **MindActWorld**，副标题为 **Evaluating Reasoning–Acting Coordination in Robotic Manipulation**。

## 三个评测维度

1. **Task-Level Reasoning · 任务级推理**：高层目标、顺序与阶段前提。
2. **Constraint-Aware Execution · 约束感知执行**：低层时间、几何、接触与稳定性要求。
3. **Adaptive Reasoning–Acting Coordination · 自适应推理—执行协同**：真实结果驱动目标、时机和计划的调整。界面简写 Adaptive Coordination / 自适应协同。

第三维是针对本 benchmark 的建议命名，并非声称已有统一标准定义。Adaptive 表示单次任务内的行为适应，不预设在线训练、参数更新或跨任务迁移。难度加压属于评测方法，不与三个能力维度并列。

## 配套方法

方法拟名 **MindAct**，拟研究 Reasoner、Executor、Coordinator 三类职责。页面明确标为构想，未声称已发布实现、权重或实测成绩。架构不作为 benchmark 参评要求。

## 实施范围

更新网站首屏、目录、元信息、页脚、导出品牌和文档叙事。保留仓库地址、兼容文件名、任务 ID 与 cognitive/motor/coupling 数据键。原任务数据、排行榜候选、媒体和 PDF 不变。历史记录与原版 PDF 保留旧名称。

## 验证

静态检查覆盖标题、术语、任务与排行榜数据一致性、资源链接及无实测成绩的占位状态。浏览器验证覆盖桌面/手机布局、目录、视频、筛选、排行榜两赛道与三个视图、下载和打印恢复。
