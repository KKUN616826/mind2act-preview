# CP03 · 动态槽架装盘

推理—执行协同

将备料区的竖直餐盘逐个装入持续移动盘架的空槽，不扰动已有餐盘。Easy 按 Start 后装入 3 盘；Medium/Hard 先拨至二档/三档，松手确认档位保持，再按 Start，分别装入 5/7 盘。跟随空槽对齐、下降、松爪并退出，让餐盘由双侧三角支架和底托稳定支撑，最后撤离。

**核心挑战：** 能否在持续移动、逐渐收紧的槽口约束下完成连续装载，并依据真实支撑状态推进任务？

## 验证能力

- 选档、启机与连续装载的阶段组织
- 移动空槽的跟踪与插入时机控制
- 竖直餐盘的姿态对准、接触插入和稳定释放
- 依据实际入槽与支撑更新装载进度

## 高层、低层与闭环证据

- 高层目标：根据档位、空槽和剩余盘数组织连续装载，维持已装载记录
- 低层效果：跟踪移动槽口，完成姿态对准、插入、稳定释放与退出
- 闭环验收：真实入槽且支撑稳定才推进装载进度；未完成选档或支撑确认时不能直接进入后继阶段

## 执行流程

Medium/Hard 拨至指定档位 → 松手确认档位保持 → 按 Start 启动盘架 → 选择当前空槽并跟踪 → 竖直对齐并下降插入 → 松爪退出并确认稳定支撑 → 连续补齐目标空槽 → 全部完成后撤离

## 难度设置

| 设置 | Easy | Medium | Hard |
|---|---|---|---|
| 装载数量与控制流程 | 3 盘；Start → 连续补齐相邻空槽 → 撤离 | 5 盘；拨二档 → 松手保持 → Start → 补位 → 撤离 | 7 盘；拨三档 → 松手保持 → Start → 补位 → 撤离 |
| 运动方式与频率压力 | 单向；12 mm/s 匀速；三个相邻空槽，同一位置通过间隔约 20 秒；首槽提前进入装载区，减少空等 | 单向；二档 16 mm/s 匀速；相邻目标空槽同一位置通过间隔约 20 秒 | 自动往复；三档巡航 20 mm/s；同一方向相邻目标空槽通过间隔约 14 秒；端部固定 0.6 秒换向，插入时保持巡航速度 |
| 插入精度（支架净间隙 / 盘厚外总余量） | 约 36.5 mm / 16 mm | 约 30.5 mm / 10 mm | 约 26.5 mm / 6 mm |
| 槽位间距与设备布局 | 槽距 240 mm，连续留 3 个相邻空槽；左来料罩、右清洗机；含缓冲段总长 6.2 m | 160 mm；左来料罩、右清洗机；含缓冲段总长 6.2 m | 140 mm；双侧清洗工位；总长 3.4 m |

## 完成条件与指标

完成本档全部 3/5/7 盘装载；餐盘实际入槽，由双侧支架与底托稳定支撑，释放与退出不扰动已有餐盘。Medium/Hard 还须完成指定选档与启机。建议评分与环境接触、入槽、支撑和稳定性判据对齐。

- 完整流程成功率与有效装载数
- 指定档位保持与启机完成率
- 实际插入姿态/位置误差
- 稳定释放率及已有餐盘扰动
- 动态窗口错失与端到端操作时延
- Hard 换向前后的装载表现

## 参数与评测说明

- 三档巡航速度为 12/16/20 mm/s，装载数量为 3/5/7 盘；Hard 自动往复，端部固定 0.6 秒换向，插入时保持巡航速度。
- 支架净间隙约为 36.5/30.5/26.5 mm；盘厚外总余量为 16/10/6 mm。数量、速度、间隙与布局同时改变，跨档差异不能归因于单一能力。
- 来源将 Medium 相邻目标空槽通过间隔写为约 20 秒，并给出 160 mm 槽距和 16 mm/s 带速。若指连续相邻槽位，其运动学间隔为 10 秒；目标槽选择或间隔描述需核对，暂不补造规则。
- 来源报告三段专家运控分别完成 3/3、5/5、7/7 装盘并通过接触、入槽、支撑和稳定性检查；这些是来源陈述，本次仅核验视频文件。
- 视频使用仿真状态的专家运控，不是学习策略测评，也不证明模型能在相同观察权限下完成任务。
