# CP05 · 电子琴复奏

耦合套件

按档位打开琴盖并取用敲击棒，用棒头敲击开始按钮以启动示范。记住琴键顺序和重复次数，提示结束后用棒头逐键复奏，最后归还工具、恢复琴盖状态并撤离。执行不要求复现示范速度，双棒可以轮流操作。

**核心挑战：** 能否将有重复的序列记忆转换为独立有效触键，并完成准备、复奏和收尾的完整任务？

## 验证能力

- 琴键身份、顺序和重复次数的序列记忆
- 棒头准确接触、触发深度与释放控制
- 双臂双棒的目标分配和空间协调
- 准备、示范启动、复奏、工具归位与合盖的进度管理

## 高层、低层与闭环证据

- 高层目标：保留琴键顺序与重复次数，管理准备和收尾
- 低层效果：棒头触发后释放，归棒稳定并恢复琴盖
- 闭环验收：有效触键才推进序列；复奏结束仍需完成收尾，无跟拍要求

## 执行流程

按档位打开琴盖 → 取用一根或两根棒 → 用棒敲开始按钮并释放 → 观察并记忆示范序列 → 逐键触发并抬棒释放 → 将所用棒稳定归位 → 按档位合盖并撤离

## 难度设置

| 设置 | Easy | Medium | Hard |
|---|---|---|---|
| 候选目标白键 | 中央 7 个 | 左右两组，共 14 个 | 左端、中央、右端，共 21 个 |
| 敲击序列 | 8 次 | 8 次 | 12 次 |
| 工具 | 单臂单棒 | 双臂双棒，可轮流操作 | 双臂双棒，可轮流操作 |
| 初始琴盖与准备 | 已打开；取一根棒 | 关闭；自行开盖、取两根棒 | 同 Medium |
| 启动示范 | 用棒敲开始按钮 | 相同 | 相同 |
| 目标区域总跨度 | 14.1 cm | 42.3 cm | 65.8 cm |
| 示范速度／执行要求 | 示范暂定 2 秒/次；执行不要求跟拍 | 相同 | 相同 |
| 收尾 | 归还一根棒并撤离，琴盖保持打开 | 归还两棒、合盖并撤离 | 同 Medium |
| 主要压力 | 局部顺序与准确触键 | 左右目标记忆、双棒轮流操作及开合盖 | 更长序列、更大跨度、更多连续同侧操作 |

## 完成条件与指标

琴键顺序和次数正确，每次由棒头真实触发后释放；工具稳定归位，琴盖恢复该档初始状态，机械臂撤离。错序、漏击、额外击打、邻键误触及工具失败均影响成功。

- 完整任务成功率与复奏序列正确率
- 漏击、额外击打和邻键误触数
- 有效触发及释放率
- 工具归位和琴盖恢复成功率
- 分阶段完成率与总执行时间（无跟拍要求）
