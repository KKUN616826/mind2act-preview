# 研究文章版 · 2026-09-22

网站按研究文章重组为动机、三个核心观点、任务设计、任务与演示、失败诊断、资源与开放问题。桌面侧栏提供文章目录，手机端改为可折叠目录。观点段落直接嵌入 P、PR3、CP02 的现有运控视频；所有原始任务与难度数据保持不变。

三个观点分别说明历史与规则如何决定当前目标、目标如何在时间和接触约束下实现、物理结果如何改变下一步计划。每个观点连接一个具体案例与对应检验方式；不将设计假设或演示写作已验证的模型结论。

组织形式参考 RLE-Bench research blog 的连续研究叙事，以及 RoboICL 页面的章节和案例解释方式。正文为 PhysCo 独立撰写，未移植参考项目的实验结果或能力主张。

## 维护

- `scripts/research_intro.html`：动机、核心观点、任务设计。
- `scripts/research.css`：文章、目录和响应式样式。
- `scripts/showcase.html`：基础模板、任务目录、诊断、资源与交互。
- `docs/PhysCo_Showcase.md`：与网页主线对应的独立研究概览。
- `python3 scripts/build.py`：生成完整 HTML 和文档。
- `python3 scripts/validate.py`：检查文章锚点、资源链接、嵌入数据和逐任务文档。

## 验证

静态资源、15 项任务及 37 段素材数据一致性通过。隔离无头 Chrome 检查了 1440px 和 390px 布局，无水平溢出；图片、互动示例、搜索、展开、视频播放、重置、深链接、手机导航通过，页面异常为空。正文三处视频复用既有素材，不增加独立视频数量。
