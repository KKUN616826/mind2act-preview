# PhysCo · 认知—动作耦合评测

PhysCo: A Benchmark for Cognitive–Motor Coupling in Robotic Manipulation

机器人完成任务，需要把“现在应该做什么”转化为真实的物理效果，并依据执行结果修订下一步。PhysCo 通过 5 项认知核心、5 项动作核心与 5 项耦合任务，检查这条闭环在历史信息、长程流程、动态时机和精细操作压力下能否持续成立。

## 高层论据：当前观察未必足以决定下一步

历史身份、订单累计量、空间绑定、未知规则和事件顺序会改变正确目标。E/P/S/F/M 分别检查这五类信息怎样用于选择对象、目标和操作顺序。高层正确性的证据应落实到目标选择、顺序和有效进度；不能仅依据模型口述推理判断。

对于可替换接口的系统，可固定执行器并提供正确历史或目标，检查任务表现是否改善。其他系统可使用可实施的观察或历史干预。需要同时报告感知歧义、执行失败与干预改变的信息权限，避免把所有错误都归为记忆失败。

## 低层论据：正确目标仍需物理实现

FR1/FR2 检查动态窗口中的响应、吞吐和连续完成能力；PR1/PR2/PR3 检查调节残差、松手稳定性和真实接触轨迹。证据来自实际抓取、释放、读数、触发和接触，而非指令是否发出。

频率压力由环境变化速度、可用动作窗口和端到端延迟共同决定。必须记录推理时环境是否持续运行，并区分有效交互频率与控制器步频。精度则需固定单位、容差、观察分辨率和稳定时长；未标定的液体剂量不能支撑绝对精度结论。

## 耦合论据：物理结果会改变后续任务状态

CP01 的实际入盘决定剩余订单，CP02 的落位与停稳决定后续装饰和盖罩，CP03 的本步剂量与工具归位决定配方阶段，CP04 的实际占用决定后续套放与盖合，CP05 的有效触键、归棒和琴盖状态共同决定完成。

因此，要同时记录高层目标、低层效果与下一次状态更新。抓空后仍将需求扣除，是进度更新错误；目标选对但未抓稳，是执行错误。无法读取内部状态的策略，应采用环境事件与后续行为作为诊断依据，不能凭演示反推其内部推理。

## 四个压力维度

| 维度 | 要测的问题 | 关键证据 |
|---|---|---|
| 记忆与规则 | 不可见的历史信息是否仍能支持当前选择？ | 身份、数量、位置绑定、映射与序列的行为正确性 |
| 长程与规划 | 多阶段操作后，哪些前提和进度仍然成立？ | 完整链成功、阶段事件、有效进度与恢复成本 |
| 动态响应与频率 | 决策和动作能否赶上目标变化？ | 可用窗口、端到端时延、漏取与有效吞吐 |
| 精细与接触 | 实际效果能否满足几何、剂量和触发约束？ | 环境侧残差、松手稳定、有效接触与释放 |

任务标签表示设计依赖，不等于已证明的能力瓶颈。CP01 的动态响应压力待标定，CP02 的档位同时改变多项变量，CP03 的剂量待标定，CP04 的空间难度待实例验证。CP05 执行不要求跟拍，不能作为独立频率压力证据。

## 证据边界与评测设计

现有视频展示场景和运控流程，不是模型评测成绩。CP03 两段视频为倒液、搅拌初步预览；CP04 目前只有场景图；CP05 已提供三档完整流程视频，Easy 无琴盖，Medium/Hard 包含开合盖。P Easy/Medium 视频仍待补充。

Coding Agents 与 E2E VLA/WAM 使用共享的任务目标和环境侧判据，分别披露接口、训练条件、观察权限与时钟条件。比较至少需要重复运行、完整轨迹和成功判定记录；能力归因还需可实施的对照或干预。最终成功率、分阶段成功率、任务特定残差和恢复成本应联合报告。
